# WeddingByAmol

**WeddingByAmol is an early-stage open-source wedding technology developer platform building hosted cloud services for modern wedding experiences.**

The project starts with a fast, lightweight hosted web surface and is intended to grow into reusable modules for event pages, media workflows, integrations, automation, and optional AI-assisted capabilities.

## Positioning

- **Stage:** Early-stage
- **Model:** Open-source core + hosted cloud services
- **Focus:** Wedding web experiences, event/media workflows, integrations, automation
- **Hosting:** Vercel-ready static deployment
- **Domain:** https://weddingbyamol.com

## Current milestone

The first milestone is deliberately small: establish a credible public product surface, connect it to the open-source repository, and create a deployable foundation for future hosted features.

## Roadmap

1. Public landing page and documentation
2. Reusable wedding/event web modules
3. Hosted APIs, storage, accounts, and integrations
4. AI-assisted media/search/curation workflows where they add real product value

## Run locally

No build system is required.

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

This repository is designed to deploy directly from the `main` branch on Vercel with zero build configuration.
